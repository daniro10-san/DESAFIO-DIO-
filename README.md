# 🧪 Projeto QA - Quality Assurance

![QA Banner](https://images.unsplash.com/photo-1516321318423-f06f85e504b3?w=1200)

## 📋 Sobre o Projeto

Este repositório reúne os artefatos desenvolvidos durante o desafio de **Quality Assurance (QA)**, contemplando documentação, fluxogramas, evidências, casos de teste e registros de execução.

O objetivo é aplicar conceitos de qualidade de software, testes manuais, documentação técnica e metodologias ágeis, demonstrando o processo completo de validação de funcionalidades.

---

## 🎯 Objetivos

- Compreender os fundamentos de Quality Assurance.
- Desenvolver documentação de testes.
- Elaborar casos de teste.
- Realizar execuções e registrar evidências.
- Utilizar ferramentas de gerenciamento de projetos.
- Aplicar boas práticas de qualidade de software.
